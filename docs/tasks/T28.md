## Forge verification and limits

Used only Forge MCP documentation tools with the unchanged manifest app ID.

- Read the Forge manifest guide. The [issue-panel reference](https://developer.atlassian.com/platform/forge/manifest-reference/modules/jira-issue-panel/)
  verifies module key uniqueness/syntax, `resource`, `resolver.function`,
  `render: native`, title and required icon. The key remains valid and unique.
- The [Icons guide](https://developer.atlassian.com/platform/forge/extend-ui-with-custom-options/#icons)
  explicitly supports SVG files and
  `icon: resource:<resource key>;<relative path to resource>` for UI Kit and
  Custom UI. The [resources reference](https://developer.atlassian.com/platform/forge/manifest-reference/resources/)
  verifies resource `key`/`path` and the 23-character key limit. The official
  [bundled-icon example](https://developer.atlassian.com/platform/forge/forge-compass-cloudwatch/)
  also shows an icon-only resource directory. The new key has 17 characters;
  the path contains the referenced SVG. No external icon URL/permission is used.
- The icon has valid SVG XML and a square 24×24 viewBox. A mandatory pixel size
  specifically for Forge issuePanel was not found in the reference; 24×24 is a
  design choice, not an asserted platform requirement. Icon rendering and
  fresh-install behavior require owner live verification.
- The [Runs on Atlassian guide](https://developer.atlassian.com/platform/forge/runs-on-atlassian-apps/)
  confirms that deploy reports eligibility and documents the requirements. The
  README records the owner's observation: on 13 Nov 2026, development deploys
  at app version 6.15.0 and later reported eligibility. This agent did not deploy
  or independently observe those logs. The program describes Marketplace badges
  for eligible Marketplace apps; this repo makes no badge/certification claim.
- The [versioning reference](https://developer.atlassian.com/platform/forge/versions/)
  lists major-version triggers; a panel-key/icon change with unchanged scopes is
  not on that list. Minor updates auto-apply within an installed major version.
  The [install CLI reference](https://developer.atlassian.com/platform/forge/cli-reference/install/)
  verifies `--upgrade`, `-e` and `--product`. Use an in-place upgrade after deploy;
  no documentation requires an uninstall/reinstall for this change. This is an
  inference from the documented versioning rules, not a panel-key migration
  guarantee. Already-open panel instance/pinning behavior during a rename could
  not be verified in docs, so treat it as a new panel and check live as below.

No new API or UI Kit prop is introduced. Every changed manifest property is
documented. Forge CLI is absent from PATH and `node_modules/.bin`, so platform
`forge lint` remains an owner check. No login/deploy/install/tunnel, git
commit/push or credential access was performed.
